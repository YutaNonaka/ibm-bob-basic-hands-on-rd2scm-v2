## 背景・目的

作成済みの日本語FAQサイト（`faq.html`）にBobのブランドを反映し、閲覧環境に応じて見やすい表示を選べるようにする。ヘッダーへのBobロゴ追加、配色のBobロゴ準拠、ダークテーマの追加を行う。

## 現在の挙動

* ヘッダーは単色背景（`#1f2328`）で、ロゴはない
* アクセント色は `#3b82d4`
* ライトテーマのみ

## 期待する挙動

* ヘッダー左上にBobロゴが表示され、クリックすると `https://www.ibm.com/products/bob` が新しいタブで開く
* サイト全体の配色がBobロゴの色（IBMブルー・パープル）になる
* ヘッダー右上の切替ボタンでライトテーマ/ダークテーマを切り替えられる。初期値はOS設定に従い、ユーザーの選択は次回以降も維持される

### 対象範囲

* `faq.html` の CSS・ヘッダーHTML・JavaScript の変更

### 対象外

* FAQコンテンツの変更
* 検索・カテゴリ絞り込み・アコーディオンの動作変更

* 既存の仕様書・実装計画書（`20261017-faq-site-*.md`）の更新

## 利用者・影響システム

* FAQサイトの閲覧者（Bobを利用するIBMer）
* 他システムへの影響なし

## 主な仕様

### 1. Bobロゴの挿入

* `bob.svg` の内容を data URI（`data:image/svg+xml`）として `faq.html` に埋め込む（外部ファイル参照なし）
* ヘッダー左上に約48px四方で表示する
* `alt` テキストは「IBM Bob」

### 2. ロゴへのリンク

* ロゴを `<a href="https://www.ibm.com/products/bob">` で囲む
* `target="_blank"` および `rel="noopener noreferrer"` を指定し、新しいタブで開く

### 3. テーマカラー（Bobロゴ準拠）

`bob.svg` の主要色: IBMブルー `#0f62fe`、パープル `#a56eff`、ダークグレー `#262626`、ライトグレー `#f4f4f4` / `#e0e0e0`

| 要素 | ライトテーマ | ダークテーマ |
|------|--------------|--------------|
| ページ背景 | `#ffffff` | `#161616` |
| 本文文字色 | `#262626` | `#f4f4f4` |
| 補助文字色 | `#57606a` | `#c6c6c6` |
| 境界線 | `#e0e0e0` | `#393939` |
| 検索ボックス背景 | `#f4f4f4` | `#262626` |
| アクセント色（フォーカス・ホバー） | `#0f62fe` | `#4589ff` |
| ヘッダー背景 | `#0f62fe` → `#a56eff` のグラデーション | 同左（ダーク用に調整が必要な場合は実装時に確認） |
| ヘッダー文字色 | `#ffffff` | `#ffffff` |
| 選択中カテゴリボタン | 背景 `#0f62fe`、文字 `#ffffff` | 背景 `#4589ff`、文字 `#161616` |

* 色はCSS変数で管理し、テーマ切替時は `<html>` の `data-theme` 属性で切り替える

### 4. ダークテーマ

* ヘッダー右上にテーマ切替ボタンを設置する
* 初期表示は `prefers-color-scheme` に従う（ダーク設定ならダークテーマ）
* ボタンクリックでライト/ダークを切り替える
* 選択は `localStorage` に保存し、保存済みの値があればOS設定より優先する
* `localStorage` が利用できない環境でもエラーにせず、切替自体は動作する
* 初期表示のちらつき（ライト→ダーク）を避けるため、テーマ判定は `<head>` 内で早期に実行する

## 制約・非機能要件

* 単一HTMLファイルで完結し、`file://` で動作すること
* 外部CDN・外部フォント・外部スクリプト・外部画像の参照禁止（ロゴのリンク先 `<a href>` は除く）
* JavaScriptでの `eval` 等の使用禁止
* 切替ボタンはキーボード操作可能で、アクセシブルなラベルを持つこと
* ダークテーマでも本文のコントラストを十分に確保すること

* 狭い画面幅でもロゴと切替ボタンが重ならないこと

## リスク・懸念点

* ダークテーマのヘッダーグラデーションはライトと同じ色を使うため、視認性に問題があれば実装時に調整を相談する
* ロゴ画像（`bob.svg`）はグラデーションの `linearGradient` ID を持つため、インライン `<svg>` ではなく data URI の `<img>` で埋め込む（ID衝突を避ける）
* `file://` 環境では `localStorage` の挙動がブラウザにより異なる場合がある（保存できない場合は毎回OS設定に従う）
