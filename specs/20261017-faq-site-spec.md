## 背景・目的

プロジェクトに `qa.md` として英語で記載されているFAQコンテンツを、利用者が日本語で参照できるよう、静的HTMLのFAQサイトとして公開する。バックエンドは持たず、単一HTMLファイルで完結する。

## 現在の挙動

`qa.md` にBobに関するFAQが英語で記載されているが、ブラウザで閲覧可能なページとしては提供されていない。

## 期待する挙動

`faq.html` をブラウザで開くと、カテゴリ別に整理された日本語のFAQページが表示される。各質問はアコーディオン形式で、クリックすると回答が開閉する。キーワード検索でFAQ項目を絞り込める。カテゴリボタンで特定カテゴリのFAQ項目を絞り込める。

## 対象範囲・対象外

### 対象範囲

* `faq.html` の新規作成（プロジェクトルート）
* `qa.md` のコンテンツを日本語に翻訳して掲載

### 対象外

* 既存ファイルの変更
* バックエンドサーバーの構築
* 多言語対応

## 利用者・影響システム

* FAQサイトの閲覧者（Bobを利用するIBMer）
* 既存システムへの影響なし

## 主な仕様

* 単一HTMLファイル（`faq.html`）として作成
* CSS・JavaScriptはHTMLファイルにインライン記述（外部ファイル参照なし）
* 外部リソース参照なし（完全自己完結）
* `qa.md` の全FAQコンテンツを日本語に翻訳して掲載
* カテゴリ構成は `qa.md` の構成に準拠:
  1. 全般（General）
  2. 使い方（Usage）
  3. 高度な機能（Advanced Features）
  4. トラブルシューティング（Troubleshooting）
* アコーディオン形式: 質問クリックで回答を開閉
* デフォルト状態: 全回答を閉じた状態で表示
* **検索機能**: テキスト入力でFAQ項目（質問・回答）をリアルタイム絞り込み。ヒットなしの場合はメッセージを表示
* **カテゴリ絞り込み**: カテゴリボタン（全て / 全般 / 使い方 / 高度な機能 / トラブルシューティング）をクリックで該当カテゴリのみ表示。検索と組み合わせ可能

## 制約・非機能要件

* バックエンド不要（ファイルをブラウザで直接開いて動作すること）
* 外部CDN・外部フォント・外部スクリプト参照禁止
* JavaScriptはセキュアな実装（eval等の使用禁止）

## UI・画面仕様

### 対象画面

FAQページ（1画面）: `faq.html`

### 画面構成・表示項目

| エリア | 内容 |
|--------|------|
| ヘッダー | ページタイトル「よくある質問（FAQ）」 |
| 検索ボックス | テキスト入力欄（プレースホルダー: 「キーワードで検索…」） |
| カテゴリフィルター | カテゴリ選択ボタン（全て / 全般 / 使い方 / 高度な機能 / トラブルシューティング） |
| カテゴリ見出し | 各カテゴリのセクション見出し |
| 質問行 | 質問テキスト＋開閉を示すアイコン（▼/▲） |
| 回答エリア | 質問に対応する回答テキスト（開いた場合のみ表示） |
| 結果なしメッセージ | 検索・絞り込みでヒットなしの場合に表示 |

### 操作・画面遷移

* 質問行をクリック → 対応する回答エリアが開く / 閉じる
* 検索ボックスに文字入力 → FAQ項目をリアルタイム絞り込み
* カテゴリボタンをクリック → 該当カテゴリのみ表示（「全て」で全表示に戻る）
* 検索とカテゴリ絞り込みの組み合わせ可能
* 単一ページ内の操作のみ。ページ遷移なし

### 表示状態

| 状態 | 内容 |
|------|------|
| 初期表示 | 全ての回答が閉じた状態、カテゴリ「全て」が選択中 |
| 質問クリック後（開） | 対応する回答エリアが表示される |
| 質問クリック後（閉） | 対応する回答エリアが非表示になる |
| 検索入力中 | 一致するFAQ項目のみ表示、カテゴリ見出しはFAQ項目が存在する場合のみ表示 |
| カテゴリ選択中 | 選択カテゴリのFAQ項目のみ表示 |
| ヒットなし | 「該当する項目が見つかりませんでした」を表示 |
