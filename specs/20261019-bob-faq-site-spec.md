* 種別: 新規実装 → 追加改修（v2）
* 作成日時: 2026-10-19T09:58:35+09:00
* 更新日時: 2026-10-19T10:57:46+09:00

## 背景・目的

`qa.md` に英語で記載されたBobのFAQを日本語化し、バックエンドを持たない静的な日本語FAQサイトとして閲覧できるようにする。利用者が目的の質問を素早く探せるよう、検索とカテゴリ絞り込みを提供する。

## 現在の挙動

* リポジトリにはFAQ原文（`qa.md`）、ロゴ（`bob.svg`）、テンプレート（`specs/`）のみが存在する。
* フロントエンド（HTML/CSS/JS）は存在しない。

## 期待する挙動

* `index.html` をブラウザで開くだけで、日本語訳されたFAQが表示される。
* キーワード検索とカテゴリ絞り込みで質問を探せる。
* 質問をクリック（またはキーボード操作）すると回答が開閉する。

## 対象範囲・対象外

### 対象範囲

* 静的サイト一式（`index.html`、`style.css`、`faq-data.js`、`app.js`）
* `qa.md` 全項目（4カテゴリ・17問）の日本語訳データ
* 検索、カテゴリ絞り込み、アコーディオン開閉、空状態表示
* レスポンシブ対応、キーボード操作、基本的なARIA対応
* 本仕様書および実装計画書

### 対象外

* バックエンド、API、データベース
* ビルド環境、フレームワーク、パッケージ管理（npm等）
* `qa.md` 自体の変更
* 多言語切替、アクセス解析
* 自動テスト基盤の導入

## 利用者・影響システム

* 利用者: Bobに関するFAQを閲覧する日本語話者
* 影響システム: なし（既存コード・システムへの変更なし）

## 主な仕様

### FAQデータ（`faq-data.js`）

* `qa.md` の見出し構造に対応する4カテゴリを持つ。

| カテゴリID | 表示名 | 元見出し | 問数 |
| --- | --- | --- | --- |
| general | 一般 | General | 5 |
| usage | 使い方 | Usage | 8 |
| advanced | 高度な機能 | Advanced Features | 2 |
| troubleshooting | トラブルシューティング | Troubleshooting | 2 |

* 各FAQは「ID、カテゴリID、質問、回答」を持つ。回答は箇条書き・太字・インラインコードを表現できる形式とする。
* 製品名・固有名詞・コマンド等（Bob、MCP、VS Code、`@/src/file.ts`、`@problems`、`/`、`.bob/rules/`、SPI、PHI、ITAR 等）は原語のまま残す。
* 回答内の文字列はテキストとして描画し、HTMLとして解釈しない（`innerHTML` に未エスケープの文字列を渡さない）。

### 検索

* 検索ボックスに入力した文字列で、質問文と回答文を対象に部分一致で絞り込む。
* 英字は大文字小文字を区別しない。前後の空白は無視する。
* 入力のたびに即時反映する。
* 検索とカテゴリ絞り込みは併用でき、両方に合致するものを表示する。

### カテゴリ絞り込み

* 「すべて / 一般 / 使い方 / 高度な機能 / トラブルシューティング」のフィルタボタンを表示する。
* 初期選択は「すべて」。選択中のボタンは視覚的に区別でき、`aria-pressed` で状態を示す。
* 各ボタンに該当件数は表示しない。

### アコーディオン

* 質問をクリック、Enter、Spaceで回答が開閉する。
* 複数の回答を同時に開ける。
* 初期状態はすべて閉じた状態とする。
* 質問のボタンに `aria-expanded` と `aria-controls` を設定する。

### 表示件数

* 絞り込み結果の件数を「N件の質問」の形式で表示する。

## 制約・非機能要件

* 素のHTML/CSS/JavaScriptのみ。外部ライブラリ、CDN、Webフォントを使用しない。
* `file://` でファイルを直接開いて動作する（ES Modules、`fetch` を使用しない）。
* 対応ブラウザ: Chrome、Edge、Firefox、Safariの最新版
* 画面幅: PC（1024px以上）、タブレット、スマホ（375px程度）
* アクセシビリティ: キーボードのみで全操作が可能。フォーカス位置が視認できる。文字と背景のコントラストをWCAG AA相当とする。

## 追加・変更仕様（v2）

### 1. ロゴリンク

* ヘッダー左上の `bob.svg` 画像を `<a>` タグでラップし、`https://www.ibm.com/products/bob` にリンクする。
* リンクは新しいタブ（`target="_blank"`）で開く。
* リンクには適切な `aria-label`（例: `"IBM Bob 製品ページ（外部リンク）"`）を設定する。
* 画像の `alt` 属性は空文字のままとする（ロゴの代替テキストはリンクの `aria-label` で補完する）。

### 2. テーマカラー変更（アクセントをパープルへ）

* アクセントカラーを `#0f62fe`（ブルー）から `#a56eff`（パープル）に変更する。
* アクセントホバーカラーを `#8a4ee0`（暗めのパープル）に変更する。
* 影響範囲: カテゴリフィルタボタンの選択状態、検索ボックス・ボタン・質問のフォーカスリングなどアクセント色が使われている箇所すべて。

### 3. ダークテーマ

* OS の設定（`prefers-color-scheme: dark`）に自動連動する。手動切替ボタンは設けない。
* ダークテーマのカラー設計:

| 変数 | ライト | ダーク |
| --- | --- | --- |
| `--bg` | `#ffffff` | `#161616` |
| `--bg-subtle` | `#f4f4f4` | `#262626` |
| `--border` | `#c6c6c6` | `#525252` |
| `--border-subtle` | `#e0e0e0` | `#393939` |
| `--text` | `#161616` | `#f4f4f4` |
| `--text-muted` | `#525252` | `#a8a8a8` |
| `--accent` | `#a56eff` | `#a56eff` |
| `--accent-hover` | `#8a4ee0` | `#be95ff` |

* ダークテーマ時も WCAG AA 相当のコントラストを維持する。
* アコーディオンのコード背景色もダークテーマ対応する（`--bg-subtle` を使用するため自動対応）。

## UI・画面仕様

### 対象画面

* FAQトップの1ページ（`index.html`）。ページ遷移は行わない。

### 画面構成・表示項目

上から順に以下を配置する。

1. ヘッダー: `bob.svg`（ロゴ）とサイトタイトル「Bob よくある質問」
2. 検索ボックス: ラベル「キーワードで検索」、プレースホルダー「質問や回答のキーワードを入力」
3. カテゴリフィルタ: 「すべて / 一般 / 使い方 / 高度な機能 / トラブルシューティング」
4. 件数表示: 「N件の質問」
5. FAQ一覧: カテゴリ見出しごとにグループ化したアコーディオン
6. 空状態メッセージ（該当なしの場合のみ）
7. フッター: 「このFAQは Bob の公式FAQ（qa.md）を日本語に翻訳したものです。」

```text
+--------------------------------------------------+
| [bob logo]  Bob よくある質問                     |
+--------------------------------------------------+
| キーワードで検索                                 |
| [ 質問や回答のキーワードを入力              ]    |
|                                                  |
| [すべて][一般][使い方][高度な機能][トラブル...]  |
|                                                  |
| 17件の質問                                       |
|                                                  |
| 一般                                             |
| +----------------------------------------------+ |
| | Bobとは何ですか？                          v | |
| +----------------------------------------------+ |
| | Bobはどのように動作しますか？              ^ | |
| |   回答本文 / 箇条書き                        | |
| +----------------------------------------------+ |
| ...                                              |
+--------------------------------------------------+
| フッター                                         |
+--------------------------------------------------+
```

### 操作・画面遷移

| 操作 | 結果 |
| --- | --- |
| 検索ボックスに入力 | 一致する質問のみ表示し、件数を更新 |
| カテゴリボタンを押下 | 該当カテゴリのみ表示。検索条件は維持 |
| 質問をクリック/Enter/Space | 回答を開閉 |
| 検索ボックスを空にする | 検索条件を解除 |

### 表示状態

* 初期表示: 全カテゴリ・全17問を表示、回答はすべて閉じた状態、フィルタは「すべて」
* 空状態: 該当なしの場合、一覧を非表示にして「条件に一致する質問が見つかりませんでした。キーワードやカテゴリを変更してください。」を表示し、件数は「0件の質問」とする
* 読み込み中・エラー・無効状態: データをJSに埋め込むため対象外
* 検索で絞り込み後も、開いた回答の開閉状態は保持しなくてよい

### 入力・バリデーション

* 検索ボックスは自由入力のみ。文字数制限・形式検証なし。
* 空文字または空白のみの場合は検索条件なしとして扱う。

### デザイン要件

* IBM Carbon風のシンプルなライトテーマ（背景は白〜淡いグレー、アクセントはパープル `#a56eff` 系、テキストは `#161616` 系）
* ダークテーマ: OS設定（`prefers-color-scheme: dark`）に自動連動。背景 `#161616`、テキスト `#f4f4f4`、アクセント `#a56eff`
* フォントはシステムフォント（日本語対応のsans-serif）
* 質問行は十分なクリック領域を確保し、ホバー・フォーカス状態を視覚化する
* レスポンシブ: コンテンツ最大幅を中央寄せで制限し、狭い幅ではカテゴリボタンが折り返す。横スクロールを発生させない
* `prefers-reduced-motion` を尊重し、アニメーションは最小限とする

## リスク・懸念点

* 翻訳は意訳を含む。固有名詞は原語を維持するが、公式の日本語表記がある場合は異なる可能性がある。
* `qa.md` が今後更新されても、`faq-data.js` には自動反映されない（手動更新が必要）。
* 回答の書式（箇条書き・太字・コード）をデータ形式で表現するため、`qa.md` をそのまま読み込む方式ではない。
* ブラウザ・実機での確認は実施者の環境に依存し、全ブラウザの網羅確認はできない。
